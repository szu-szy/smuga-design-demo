# Smuga Design - demo strony

Statyczne demo nowej strony pracowni Smuga Design (arch. wn. Wioleta Siemieniuk), przygotowane przez Impact Agencja.

- Strony generuje `build.py` (python3 build.py), style `assets/style.css`, skrypty `assets/app.js`.
- Zdjęcia: okładki projektów z Behance Smuga Design oraz zdjęcia realizacji MNC Concept.
- Teksty opisów, ceny i część metryczek są robocze, do uzupełnienia z klientką.
- Strona ma noindex, to tylko podgląd.
